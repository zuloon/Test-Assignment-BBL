# T07 - Hardening and Submission

## Goal

Prepare the project for grading with stronger verification and complete submission evidence.

## Full-Stack Slice

- Adversarial auth/privacy test pass.
- Final backend and frontend build/test scripts.
- Complete `README.md`.
- Complete `AI_WORKFLOW.md`.
- Update `API_DESIGN.md` to match actual implementation.
- Update `DECISIONS.md` with any new decisions.
- Add real transcript excerpts under `transcripts/`.
- Verify `AGENTS.md` and `.agent/` are genuinely useful.

## Acceptance Criteria

- Every README claim has a test, manual smoke note, or explicit limitation.
- API docs match implemented behavior.
- Known gaps are documented honestly.
- Commit history shows the ticket-by-ticket development path.
- Submission includes all required artifacts from the PDF.

## Automated Tests

- Backend unit/e2e suite passes.
- Frontend tests pass.
- Backend build passes.
- Frontend build passes.
- Any lint/type checks pass or failures are documented with rationale.

## Manual Smoke Test

- Fresh install.
- Run backend.
- Run frontend.
- Login with Auth0.
- Exercise collections, bookmarks, delete actions, and sharing.
