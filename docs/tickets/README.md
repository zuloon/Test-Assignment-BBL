# Vertical Feature Ticket Plan

Use these tickets as the implementation order. Each ticket should deliver a user-testable slice and finish with focused automated checks.

The rule for each ticket:

1. implement the smallest full-stack slice that makes the feature usable,
2. add backend tests for security and data rules,
3. add frontend tests where the UI behavior is meaningful,
4. manually smoke test the feature,
5. update docs/transcripts,
6. commit before starting the next ticket.
